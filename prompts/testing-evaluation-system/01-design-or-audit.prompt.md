# Testing & Eval: choose the requested deliverable

This compatibility entry preserves existing links. Apply [the task contract](../_shared/task-contract.md), then load only the needed route:

- **Design a strategy or plan:** [Design an evidence system](01-design-evidence-system.prompt.md). Deliver concrete coverage, criteria, architecture, and execution prerequisites using available context.
- **Assess current implementation:** [Audit an existing system](01-audit-existing-system.prompt.md). Ground current-state findings in inspected evidence and mark access limits.
- **Both explicitly requested:** perform the scoped audit and then the design, separating facts from proposals.

These are alternative routes, not required sequential stages. Implementation and running measurements use the separate workflows in [README](README.md).
